# Бот расписания информатики

Telegram-бот на Python 3.10+ принимает DOCX и показывает уроки информатики из присланного файла, без проверки даты для **7А, 7Б, 7В, 7Г, 7Д, 7З, 8А, 8Б, 8Г, 8З, 8Е**. Проект независим от сайта в родительской папке.

## Запуск (Windows PowerShell)

Откройте терминал в этой папке:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`. Вставьте полученный токен в `.env` после `TELEGRAM_BOT_TOKEN=`. Не публикуйте токен. При необходимости измените `TIMEZONE` (по умолчанию `Asia/Krasnoyarsk`).

```powershell
.\.venv\Scripts\python.exe bot.py
```

Откройте своего бота в Telegram, нажмите `/start` и отправьте файл как документ. Бот работает, пока запущен процесс и доступен интернет. Остановка: Ctrl+C.

Linux/macOS: `python3 -m venv .venv`, `.venv/bin/pip install -r requirements.txt`, `cp .env.example .env`, после заполнения токена — `.venv/bin/python bot.py`.

## Запуск на сервере через Docker

На Linux-сервере установите [Docker Engine с Compose](https://docs.docker.com/engine/install/).
Скопируйте папку `informatics_bot` на сервер (без `.venv` и `__pycache__`) и перейдите в неё.
Python на сервере устанавливать не требуется: образ использует Python 3.12.

Создайте `.env`, если его ещё нет:

```bash
cp -n .env.example .env
nano .env
```

Укажите `TELEGRAM_BOT_TOKEN` и `TIMEZONE`. Проверьте время в `bells.json`.
Остановите локально запущенного бота с тем же токеном: для polling должен работать один экземпляр.

```bash
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 -f bot
```

Ctrl+C завершает просмотр логов; бот продолжает работать в фоне.
Проверьте работу, отправив DOCX в Telegram. Входящие порты открывать не нужно:
бот сам обращается к Telegram по HTTPS, поэтому серверу нужен исходящий доступ в интернет.
Контейнер автоматически перезапускается при сбое и после перезагрузки сервера,
если служба Docker запускается автоматически и контейнер не был остановлен вручную.

Управление:

```bash
# После изменения bells.json
docker compose restart bot

# После изменения .env
docker compose up -d --force-recreate

# После обновления кода или requirements.txt
docker compose up -d --build

# Остановка и удаление контейнера (локальные .env и bells.json сохраняются)
docker compose down
```

Токен передаётся через `.env` при запуске и не включается в образ.
`bells.json` подключается из папки на сервере только для чтения.
Временные DOCX обрабатываются в `/tmp` контейнера и удаляются после обработки.
Настройки запуска описаны в [справочнике Docker Compose](https://docs.docker.com/reference/compose-file/services/).

## Расписание звонков

В исходном документе есть только номера уроков. Поэтому `bells.json` изначально пустой: бот не придумывает время. Заполните его реальными звонками школы и перезапустите бота. Формат (значения ниже — только пример, не реальные звонки):

```json
{
  "1": "08:00–08:40",
  "2": "08:50–09:30",
  "1-7": "14:00–14:40",
  "2-8": "14:50–15:30"
}
```

Добавьте все нужные номера. Ключи `1-7` и `2-8` соответствуют обозначениям второй смены в DOCX; они независимы от `1` и `2`. Без настройки выводится номер урока и «время не настроено».

## Поддерживаемый DOCX

Парсер адаптирован под найденный `Расписание на 11.09.docx`:

- Один день на документ. Заголовок и дата не проверяются; подходит и файл без даты.
- Классы в заголовках столбцов, например `7а 3-22`, `7 д 3-20`, `8 е 2-17`.
- Номер урока в отдельном столбце слева от соответствующей группы классов; поддерживаются две смены в одной таблице.
- Предметы `Информатика`, `инф`, `ин ф`, в том числе совместно с другим предметом. Для подгрупп сохраняется весь текст ячейки: это не утверждение, что весь класс учится одновременно.

Выводятся только найденные занятия по порядку уроков в течение дня; 1-7 второй смены идёт после 6-го урока. Классы без информатики не перечисляются. Недельные таблицы, фотографии, вложенные таблицы, произвольная верстка не поддерживаются. Лимит DOCX — 10 МБ (30 МБ после распаковки). Загруженный файл удаляется после обработки; история расписаний не сохраняется.

## Проверка без Telegram

Из папки бота:

```powershell
.\.venv\Scripts\python.exe schedule.py "..\Расписание на 11.09.docx" --date 2026-09-11
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`--date` предназначен для локальной проверки; дата используется только в подписи «обработан», не для фильтрации уроков.

Использованы [python-docx](https://python-docx.readthedocs.io/en/latest/) и [python-telegram-bot](https://docs.python-telegram-bot.org/).
